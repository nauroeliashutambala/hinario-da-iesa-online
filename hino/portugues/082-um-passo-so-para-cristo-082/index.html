HINO 82 · Português

Um passo só para Cristo!

1. Um passo só para Cristo! Porque mais demorar? Ele oferece agora, A paz e bem-estar. Um passo só! Um passo só! Vem ó pecador; Com arrependimento, Tudo Lhe confessando! Um passo só pra Cristo! Oh! Vem sem demorar! 2. Um passo só pra Cristo! Das trevas para a luz; para inefável gozo, ao lado de Jesus, Um passo só! Um passo só! Vem ó pecador; Com arrependimento, Tudo Lhe confessando! Um passo só pra Cristo! Oh! Vem sem demorar! 3. Um passo só pra Cristo! Oh! Vem decide já! Com terno amor te espera, perdão te outorgará. Um passo só! Um passo só! Vem ó pecador; Com arrependimento, Tudo Lhe confessando! Um passo só pra Cristo! Oh! Vem sem demorar! 4. Um passo só p’ra Cristo! Oh! Deixa todo o mal; as seduções do mundo, E aceita a paz real. Um passo só! Um passo só! Vem ó pecador; Com arrependimento, Tudo Lhe confessando! Um passo só pra Cristo! Oh! Vem sem demorar! 5. Um passo só p’ra Cristo! Mui breve a morte vem; como viver sem ele, na eternidade, além. Um passo só! Um passo só! Vem ó pecador; Com arrependimento, Tudo Lhe confessando! Um passo só pra Cristo! Oh! Vem sem demorar! 6. Um passo só pra Cristo! Oh! Clama pecador: “salva-me que eu pereço, socorra-me senhor!” Um passo só! Um passo só! Vem ó pecador; Com arrependimento, Tudo Lhe confessando! Um passo só pra Cristo! Oh! Vem sem demorar!
