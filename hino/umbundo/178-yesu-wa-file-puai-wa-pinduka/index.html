HINO 178 · Umbundo

Yesu wa file puãi wa pinduka

O mopela hu, o mopela hu, Yesu ocili o mopela, O mopela hu 1. Yesu wa file puãi wa pinduka, Ha ecela ovakandu. Ndu sole omo eye a fila, O mopela hu 2. Ndaño ayonjo a lua a njonja, Ñala Yesu wa a yula. Ndaño ku keya olonatoma, O mopela hu 3. Ocindululu haeye Satana, O nduisila ayonjo. Yesu wo yula komindikiso, O mopela hu. 4. Ndaño upongo levi vi vala Vi sanga ndukua Yesu, Eye ñolela ndu vilikiya, O mopela hu.
