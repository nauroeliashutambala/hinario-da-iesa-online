HINO 260 · Umbundo

Evi via Yesu njongola

Haimo sia telele. Haimo sia telele. Evi via Yesu njongola. Vi pepa; ka vi kumi pua. 1. Evi via Yesu njongola. Evi via Yesu mbangula. Ndaño via lua si tela, Vi pepa; ka vi kumi pua, 2. Ndi lisikama la Yesu, Ndi lipasola laye hu. Mbangola laye kulika. Ndi kuete laye ongeva. 3. Eci ndu muila komangu Yina yulamba kovailu Nongeka vali lesanju Kolombangulo vi enda hu.
