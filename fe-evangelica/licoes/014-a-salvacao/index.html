A SALVAÇÃO

A SALVAÇÃO

Leitura
João 3.1-15
Pergunta
Que acontece quando o homem é salvo?
Resposta
Logo que o homem é salvo, torna-se uma nova criatura em Cristo.

Texto

Quando alguém está unido com cristo, é uma nova pessoa; acabou-se o que é velho, e o que é novo já veio (2 Cor. 5.17).

Explicação

  • O homem salvo:
  • Nasceu de novo, quer dizer que recebeu a vida eterna (João 3.3).
  • É adoptado, tornou-se filho de Deus (João 1.12, Rom.8.14).
  • É perdoado, os seus pecados são apagados (Act. 3.19).
  • É justificado, perante Deus é como se nunca tivesse pecado (Rom. 5.1).
  • É remitido, libertado do seu antigo dono (Rom. 6.18).
  • É reconciliado com Deus, tem paz com ele (2 Cor. 5.19-21).
  • É purificado, posto a parte para o serviço do senhor (2 Tim. 2.21).

Oração

Oremos para que Deus faça de nós verdadeiros servos seus.

Notas

  • 2 OvaKorinthi = 2 Coríntios
  • Ovilinga = Atos
  • 2 Timoteu = 2 Timóteo

EYOVO

Leitura
Yoane 3.1-15
Pergunta
Cina comunhua amapopilha ukala ūeni?
Resposta
Cina vala omnunhu amapopilhua, ulinga omunthu omupe mu Kristu.

Texto

Ine umue uli mu Kristu, walinga omunthu umue omupe. Ovipuka aviho ovikulu viapita, pahe aviho vialinga ovipe (2 OvaKorinthi 5.17).

Explicação

  • Omunthu wapopilua ukala ngoco:
  • Wacima tuvali, cikahi okuti, watambula omucnyo wahapu (Yoane 5.3).
  • Watambula omphangu you'mona, walinga oMona wa Huku (Yoane 1.12, OvaRoma 8.14).
  • Waevelua, Huku wemusekuna ononkhali mbae (Ovilinga 3.19).
  • Walingisua ondalawa, k'omaiho a Huku ukahi ngou wahalingile cimue octvi (OvaRoma 5.1).
  • Wainkululua, wayovolua ku muene waew'okohale (OvaRoma 6.18).
  • Wahonyekua na Huku, una ombembua nae (2 OvaKorinthi 5.19-21).
  • Wasukulua, pahe uhivilua ovilinga vi'olJamba Yesu (2 Timoteu 2.21).

Oração

Tulikuambelei okuti, Huku utu lingisa ovakuerije vae vocili.

Notas

  • 2 OvaKorinthi = 2 Coríntios
  • Ovilinga = Atos
  • 2 Timoteu = 2 Timóteo
